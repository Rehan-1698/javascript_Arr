# 🚀 JavaScript Arrays — Learning & Practice

A beginner-friendly repository dedicated to learning **JavaScript Arrays** from the basics and improving problem-solving skills through hands-on practice.

This repository contains simple examples, concepts, and practice problems that help build a strong foundation in JavaScript Arrays.

---

## 📌 About This Repository

Arrays are one of the most important data structures in JavaScript.

This repository is created to understand how arrays work internally and how to solve different problems using basic JavaScript logic.

The focus is on **understanding the concept and writing the logic**, rather than simply memorizing methods.

## ▶️ How to Run

### 1. Clone the repository

```bash
git clone https://github.com/Rehan-1698/javascript_Arr.git
```

### 2. Open the project

```bash
cd javascript_Arr
```

### 3. Run any JavaScript file

```bash
node basics_1.js
```

You can also run other files:

```bash
node basic_2.js
node problem_1.js
node problem-2.js
```
